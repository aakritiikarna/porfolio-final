# Personal Portfolio

A modern and responsive personal portfolio website built with **Next.js** to showcase my skills, projects, experience, research, and achievements.

## ✨ Overview

This portfolio is designed to provide a simple and professional way to explore my work and technical background. It includes dedicated sections for my introduction, technical skills, experience, projects, research, and contact information.

The website is built with a focus on:

* Clean and responsive UI
* Modern web development practices
* Reusable React components
* Fast page performance
* Responsive design across devices
* Easy-to-maintain project structure

## 🛠️ Getting Started

To run the project locally, first clone the repository:

```bash
git clone https://github.com/aakritiikarna/porfolio-final.git
```

Navigate to the project directory:

```bash
cd porfolio-final
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🔐 Environment Variables

If the project requires environment variables, create a `.env.local` file based on `.env.example`.

```bash
cp .env.example .env.local
```

Add the required values to `.env.local`.

> Do not commit `.env.local` or any private API keys to GitHub.

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To run the production version locally:

```bash
npm start
```
